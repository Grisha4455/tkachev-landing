# Лендинг программы партнёрства по Shopify

Продающий лендинг для эксперта по запуску онлайн-магазинов на Shopify: описание услуг, этапы работы, видео и страница благодарности после заявки.

**Сайт:** https://tkachev-landing.vercel.app

## Что внутри

- Продающий первый экран и блоки с преимуществами программы
- Секции услуг: готовый магазин, товары, рекламные связки, воронка продаж, поставщики, платёжные решения, обучение
- Видео-вставки
- Анимации появления блоков при прокрутке (IntersectionObserver)
- Отдельная страница благодарности `thank-you.html`
- Адаптивная вёрстка под телефоны, планшеты и десктоп

## Стек

HTML, CSS, JavaScript. Деплой — Vercel.

## Запуск

Откройте `index.html` в браузере.
